MARS BIO LAB v2 — QUEST QUICK START

WHAT'S NEW
- Safe teleportation between stations (less motion sickness)
- 3 unlockable biology stations
- Progress tracker
- Local sound effects + ambient hum
- Final quiz unlocked after completing all stations
- Student credit included

UPLOAD TO GITHUB PAGES
1. Create a GitHub repository named: mars-bio-lab
2. Upload ALL files from this folder to the repository root.
3. GitHub > Settings > Pages
4. Build and deployment > Deploy from a branch
5. Branch: main
6. Folder: / (root)
7. Save
8. Open the generated HTTPS link in Meta Quest Browser.
9. Press Enter VR.

QUEST CONTROLS
- Point with controller laser.
- Trigger = click.
- Use glowing teleport pads to move.
- Press each station's UNLOCK button.
- Complete all 3 stations to unlock the final challenge.

IMPORTANT
- Keep Wi-Fi on because A-Frame loads from aframe.io.
- For the school demo, open the site once before presenting to confirm everything loads.
- This is an educational prototype, not a medical simulation.
